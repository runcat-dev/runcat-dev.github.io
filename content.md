### Cute

The cuteness that captivates people is the greatest value.
:::

:::warp useful

### Useful

Yet, it must also possess a utility that goes beyond being just a joke.
:::

RunCat is hobby software designed for the general public. Rather than targeting computer experts, we aim to make it possible even for those who are not tech-savvy to check the health of their computers.

Therefore, we do not pursue overly niche features or minute customizations. When it comes to data visualization, we prioritize making things easy to understand for everyone and place high importance on accessibility.

Furthermore, we always keep maintenance costs in mind when implementing features. We strive to maintain clean source code.

We look forward to welcoming any developers who resonate with these values.

## FAQ

:::details What is RunCat?
The original RunCat is a macOS utility that visualizes CPU usage by varying the playback speed of a running-cat keyframe animation. A Windows version based on the same concept followed. More recently, an endless runner game where you control the running cat to dodge obstacles was developed and ported to handheld platforms such as the GBA and Playdate.
:::

:::details How do I report a bug or request a feature?
Open an Issue or Pull Request on the relevant project repository under [github.com/runcat-dev](https://github.com/runcat-dev). Please don't bring bug reports or feature requests into Discord — Issues and Pull Requests keep them searchable and tied to the code.
:::

:::details Tips for Contributing

- Follow the Issue and Pull Request templates.
- Check for similar Issues or Pull Requests before creating a new one.
- Keep each Issue or Pull Request focused on a single topic. Bundling unrelated topics into one increases review cost and makes the thread harder to manage.
- Address each comment in a Pull Request individually rather than replying to them all at once. The larger the diff in a single commit, the higher the review cost becomes.

:::
